# Internationalization (i18n)

Vydra includes a lightweight, fully reactive internationalization system designed for scalable applications. It leverages modern web primitives to ensure performance and reactivity:

- **Lit Context API** for providing translations seamlessly down the DOM tree.
- **Provider / Consumer pattern** to manage language state efficiently.
- **Reactive Mixins** (`I18nMixin`) to automatically re-render components when translations change.
- **Dynamic loading** to only fetch translations over the network when requested.

Translations are stored in JSON files and shared across the application.

---

## 1. Translation Files

Translation files should be placed in your application's public folder, usually under `/public/locales/`.

```txt
/public
  /locales
    en.json
    es.json
```

**Important Rule: Use Dot Notation**

Vydra's i18n parser requires a flat JSON structure using dot notation for namespacing. Nested JSON objects are **not supported**.

✅ **Correct:**
```json
{
  "nav.docs": "Documentation",
  "nav.showcase": "Showcase",
  "button.save": "Save"
}
```

❌ **Incorrect:**
```json
{
  "nav": {
    "docs": "Documentation"
  }
}
```

## 2. Initializing i18n

The i18n system must be configured and loaded *before* the application initializes the router and mounts to the DOM.

```typescript
import { VydraRouter } from "@vydra-js/router";
import { i18n } from "@vydra-js/i18n";
import { VydraOutlet } from "./app/app.component";
import { routes } from "./app/router/app.router";

// 1. Configure the base path for locating JSON files
i18n.setBasePath("/");

// 2. Await the initial language load
await i18n.load("en");

// 3. Initialize the application normally
const mountPoint = document.getElementById("app")!;
const outlet = document.createElement(VydraOutlet.is) as any;
mountPoint.appendChild(outlet);

const router = new VydraRouter({ basePath: "/", mountPoint, outlet, routes });
router.init();
```

## 3. Base Paths in Microfrontends

Configuring `setBasePath` correctly is critical, especially in a microfrontend context. The i18n system requests translations from: `[basePath]/locales/[lang].json`

**For Single-SPA Applications (Standalone):**
If your app runs at the root domain (`http://localhost:4321/`), use `/`.
```typescript
i18n.setBasePath("/"); 
// Requests -> http://localhost:4321/locales/en.json
```

**For Microfrontend Applications:**
In a Root Orchestrator, your microfrontend's assets might be hosted at a completely different URL or subdirectory. You must provide the exact absolute URL or prefixed path where the MFE is hosted.
```typescript
i18n.setBasePath("http://localhost:4321/docs");
// Requests -> http://localhost:4321/docs/locales/en.json
```

## 4. Providing the i18n Context

For the reactivity to work, the `i18n` context must be provided at the highest level of your component tree, typically inside your Custom `VydraOutlet`.

```typescript
import { Inject, VydraOutletBase } from "@vydra-js/core";
import { i18n, I18nAdapter, i18nContext } from "@vydra-js/i18n";
import { provide } from "@lit/context";
import { RootService } from "./services/root.bus";

export class VydraOutlet extends VydraOutletBase {
  static is = "vydra-docs-app-outlet";

  // Create the adapter
  i18nAdapter = new I18nAdapter();
  rootBus = Inject(RootService);

  // Provide the context to all child elements
  @provide({ context: i18nContext })
  i18n = this.i18nAdapter;

  constructor() {
    super();
    // Listen to global bus events to switch language across MFEs
    this.rootBus.onSetLangRequested((lang) => {
      this.setLanguage(lang);
    });
  }

  async setLanguage(lang: string) {
    // Fetch the new JSON from the network
    await i18n.load(lang);
    // Notify the application to trigger a re-render
    i18n.setLanguage(lang);
  }
}
```

## 5. Consuming Translations in Components

To use translations and react to language changes automatically, a component must extend the `I18nMixin`.

```typescript
import { html, LitElement } from "lit";
import { ScopedElementsMixin } from "@open-wc/scoped-elements/lit-element.js";
import { I18nMixin } from "@vydra-js/i18n";

// Wrap your base class with I18nMixin
export class HomePage extends I18nMixin(ScopedElementsMixin(LitElement)) {
  
  render() {
    return html`
      <h1>${this.t("nav.docs")}</h1>
      <button>${this.t("button.save")}</button>
    `;
  }
}
```

### Reactive Updates
When `i18n.setLanguage(lang)` is called, the context updates globally. Because your component consumes this context via `I18nMixin`, Lit automatically schedules an efficient re-render, swapping out the text instantaneously without requiring a page reload.

---

## Best Practices

- **Descriptive Keys:** Prefer meaningful and descriptive key names. (`nav.documentation` is better than just `docs`).
- **Group by Feature:** Organize keys logically by view or feature (e.g., `auth.login.title`, `dashboard.metrics.users`).
- **Load Languages Early:** Always await `i18n.load(...)` before bootstrapping the application to prevent layout shifts or flashing translation keys on the screen.
